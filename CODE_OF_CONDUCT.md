# Code of Conduct

We follow the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Our standard.** Be respectful and constructive. Assume good faith, critique ideas and results rather than people, welcome newcomers, and credit others' work. Benchmark discussions should be evidence-based: share configurations and result files so others can reproduce them.

**Unacceptable behaviour** includes harassment, discrimination, personal attacks, doxxing, deliberately misleading benchmark claims, and publishing others' private information.

**Enforcement.** Maintainers may remove comments, issues or contributions that violate this code and may ban repeat offenders. Report concerns privately to the maintainers through GitHub (a private security advisory or a direct message to a maintainer); reports are handled confidentially.
